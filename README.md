# RORO / Go To Wealth

เว็บเกมจำลองการวางแผนการเงินและการใช้พลังงานในชีวิตประจำวัน

## วิธีเปิดเกม
1. แตกไฟล์ ZIP ลงในเครื่อง
2. เปิด `work.html` ด้วย Chrome, Edge หรือ Firefox รุ่นใหม่
3. เลือกอาชีพและเริ่มเล่นได้ทันที

## ฟีเจอร์ที่เพิ่มในรุ่นนี้
- แถบความก้าวหน้าผู้เล่น: เลเวล, EXP และแถบ EXP ที่อัปเดตตามการเล่น
- ได้ EXP จากการทำกิจกรรมและจบวัน พร้อมแจ้งเตือนเมื่อเลเวลอัป
- ภารกิจรอบ: ทำกิจกรรมให้ครบ 5 ครั้ง พร้อมแสดงความคืบหน้า
- ปรับแผงความก้าวหน้าให้รองรับหน้าจอมือถือ

## หมายเหตุ
- ความก้าวหน้าระดับ/EXP เป็นของรอบที่กำลังเล่น และเริ่มใหม่เมื่อเริ่มเกมรอบใหม่
- เกมยังเป็นเว็บต้นแบบฝั่งไคลเอนต์ การบันทึกความก้าวหน้าแบบถาวรหรือระบบบัญชีออนไลน์ยังไม่ได้เพิ่ม
- ไฟล์ภาพ/เสียงภายนอกที่อ้างอิงใน HTML อาจต้องอยู่ในตำแหน่งที่เกมคาดหวังเพื่อให้เล่นสื่อได้ครบ


## ระบบเพิ่มเติม: Difficulty Scaling และ Random Daily Events
- ความยากเพิ่มทุก 7 วัน: กิจกรรมใช้พลังงานเพิ่ม และพลังงานฟื้นฟูเมื่อเริ่มวันใหม่ลดลงตามระดับ
- มีเหตุการณ์สุ่มทุกวัน ทั้งเหตุการณ์บวกและลบ เช่น โบนัส พลังงานฟื้นฟู พายุ ค่าครองชีพ และทรัพยากรขาดแคลน
- เพิ่มเหตุการณ์ได้โดยเพิ่ม object ใหม่ในอาร์เรย์ `DAILY_EVENTS` พร้อม `id`, `name`, `icon`, `type`, `weight`, `description` และ `apply()`
